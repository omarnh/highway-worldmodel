# Highway World Model (LeWorldModel-style JEPA)

A LeWorldModel-style joint-embedding world model trained on the `highway-fast-v0`
Kinematics environment. A single encoder learns a collapse-free latent (kept
isotropic by SIGReg), and an action-conditioned predictor learns the latent
dynamics. Trained end-to-end — no target network, no stop-gradient, no EMA.

## Method

- **Observation:** Kinematics, 5 vehicles × 5 features = 25 numbers.
- **Encoder:** MLP 25→128→128→64.
- **Projector:** Linear(64→64) + BatchNorm (prediction and SIGReg act on the projected embedding).
- **Predictor:** MLP over [3-frame history + action block] → next embedding (direct).
- **Loss:** single-step teacher-forced next-embedding MSE + λ·SIGReg (Epps–Pulley,
  isotropic-Gaussian regularizer). No stop-grad / EMA.
- **Data:** frame-skip-5 sub-trajectories (windows of 4 kept frames + 3 action blocks;
  a block = 5 discrete meta-actions as one-hots).

### Deviations from the LeWorldModel paper (arXiv:2603.19312)
- MLP encoder/predictor on the Kinematics **vector** instead of ViT-on-pixels + AdaLN.
- **λ = 1.0** (paper uses 0.1, which collapsed in this MLP/vector/M=256 setup).
- SIGReg uses M=256 random projections.

## Results (held-out)

- No collapse: latent_std ≈ 0.98, eff_rank ≈ 12, off-diagonal cov ≈ 0.28.
- Informative latent: linear-probe readout R² 0.92–0.99 (ego speed, lane, gap, lead speed).
- 1-step next-embedding prediction (cosine, lower is better):
  world model ≈ 0.17 vs no-op ≈ 0.50 vs shuffled-action ≈ 0.49 (beats both; uses the action).

See `lewm2_results.png`.

## Surprise & reasoning (on top of the world model)

- **Surprise** = 1-step prediction error, ‖predicted next embedding − real next embedding‖.
  Low during normal driving, spikes on an unexpected event (`lewm2_surprise.py`, `lewm2_surprise.png`).
- **Reasoning / Q per action** (`lewm2_q.py`): from a state, take an action → get a
  representation, repeat for a few steps; score each future representation by its surprise
  under SIGReg's N(0,I), `0.5*||z||^2` (= −log p); **sum** them → Q for that action sequence.
  Lower Q = the future stays more expected. Example at a surprising state: holding steady
  scores lowest Q, accelerating scores highest.

## Run

```bash
pip install -r requirements.txt
python lewm2_data.py      # collect highway sub-trajectories -> lewm2_data.npz
python lewm2_train.py     # train -> lewm2_ckpt.pt
python lewm2_verify.py    # world-model metrics + figure
python lewm2_surprise.py  # surprise signal (spikes on unexpected event)
python lewm2_q.py         # Q = summed future surprise per action sequence
```

## Files

| file | purpose |
|------|---------|
| `jepa.py` | shared helpers (MLP, collapse metrics) |
| `lewm2.py` | model: encoder, BN projector, action-conditioned predictor, SIGReg |
| `lewm2_data.py` | highway sub-trajectory collection |
| `lewm2_train.py` | training loop |
| `lewm2_verify.py` | world-model verification + plot |
| `lewm2_surprise.py` | surprise signal (1-step prediction error) |
| `lewm2_q.py` | Q = summed future surprise per action sequence |
| `lewm2_ckpt.pt` | trained checkpoint |

`lewm2_data.npz` is regenerated by `lewm2_data.py` (git-ignored).
